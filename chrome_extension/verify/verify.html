What this check does — and what it doesn't

✓ The signature proves the file was produced by Revision Banner and was not casually hand-edited after export (any change to the data breaks it).
✓ The cross-check compares the student's claimed activity days and edit counts with the document's version history on Google's servers — which students cannot edit or delete.
✗ It cannot prove where text originally came from, catch typing simulators, or verify work done in other tools. A mismatch is a reason to ask questions, not a verdict.
