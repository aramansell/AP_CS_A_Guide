AI analysis — optional, bring your own key

Adds an “Explain with AI” button to the score breakdown (click the score in the banner → Details). When you click it, the extension sends only writing-process metadata — timings, sizes, counts and the locally-computed signals — to an OpenAI-compatible endpoint of your choice, with your key. Document text is never sent. Nothing leaves this machine unless you click that button.

Experimental — Drive API metadata sync

Optional higher-fidelity tier: revision metadata (who saved, when, sizes) straight from the Google Drive API using your own OAuth client. Requires a Google Cloud project; see README for the 5-minute setup. Everything else in the banner works without this.

About

Revision Banner mirrors what teachers love about revisionhistory.com-style tools: edit counts, active time, work sessions, contributors and paste flags — without sending anything anywhere. Metrics combine up to four independent sources (live tracking, the document's own version history, network op captures, optional Drive API), and every number on the banner shows where it came from. The writing-process score is a heuristic conversation starter — not proof of misconduct or AI use.
