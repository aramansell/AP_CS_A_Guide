8.5b — Convolution: Blur, Sharpen, Edge Detect

Season 2: beyond the exam. This topic is no longer tested (the 2025 CED removed inheritance from the exam). We build it after May 12 because it makes the RPG engine dramatically better, and because you are ready for it. Pure craft, zero test anxiety.
Basic Application ~25 min

Requirement 1: Box Blur

A blur replaces each pixel with the average of its 3×3 neighborhood. That sliding 3×3 window is called a kernel.

Kernel (each cell = 1/9):
┌─────────────┐
│ 1/9  1/9  1/9 │
│ 1/9  1/9  1/9 │   Apply to every pixel
│ 1/9  1/9  1/9 │
└─────────────┘

Before:           After:
██  ██  ██       ▒▒  ▒▒  ▒▒
██  ██  ██  →    ▒▒  ▒▒  ▒▒
██  ██  ██       ▒▒  ▒▒  ▒▒

Build boxBlur(int[][] img) that returns a new image. For pixels at the border (row 0, col 0, etc), only average the valid neighbors — don't go out of bounds.

Socratic Checkpoint

You need to modify a new array (not the original) while reading from the original. Why? What would happen if you modified pixels in-place while reading?

Requirement 2: Edge Detection

Edges are places where pixel values change rapidly. A simple edge detector compares each pixel to its right and bottom neighbors:

For pixel at [r][c]:
  rightDiff = |img[r][c] - img[r][c+1]|
  downDiff  = |img[r][c] - img[r+1][c]|
  edge[r][c] = Math.max(rightDiff, downDiff)

If the difference is large (> 50), there's an edge. Draw a horizontal gradient (0 to 255 across the image). Run your edge detector. Where does it fire? Where does it stay silent? Why?

Socratic Checkpoint

A gradient has no sharp edges — values change smoothly. What kind of image WOULD trigger edge detection? Draw a sharp jump (0→255 between adjacent pixels) and test. Now draw a checkerboard pattern. Which method is it — row-major or column-major — and does the edge detection pattern match?

Requirement 3: Heat Map Filter

Transform grayscale into a "heat map" where:

  • 0-63 → deep blue (print "B")
  • 64-127 → green (print "G")
  • 128-191 → orange (print "O")
  • 192-255 → red (print "R")

Generate a gradient image, apply the heat map, and describe what you see. Now apply edge detection FIRST, then the heat map. Now what do you see?

Checkpoint — before moving on, you must be able to:

  • Implement a box blur using a 3×3 neighborhood average
  • Detect edges by comparing adjacent pixel values
  • Explain why convolution requires a separate output array
  • Combine filters (edge detect → heat map) into a processing pipeline
