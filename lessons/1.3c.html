1.3c — Random Formula: Test, Trace & Connect

Discovery Lab ~20 min

You've run experiments and built a dice roller. Now prove you own the formula — not by memorizing it, but by being able to rebuild it from first principles.

Part 1: Blank Page Challenge

Close all tabs. On a blank piece of paper (or a blank file), write:

  1. The signature and return range of Math.random() — from memory
  2. The formula for a random integer from min to max, inclusive
  3. Test it: roll a d20 (1–20) and a d100 (1–100). Verify the range.

Socratic Checkpoint

If you had to explain the formula to someone who's never coded, could you? Try it. The real test of understanding is whether you can teach it.

Part 2: The Casting Trap — Can You Spot It?

For each line below, predict the output before running it:

System.out.println(  (int) Math.random() * 10  );
System.out.println(  (int) (Math.random() * 10)  );
System.out.println(  (int) (Math.random() * 6) + 1  );
System.out.println(  (int) Math.random() * 6 + 1  );

Write your predictions. Then test. How many did you get right?

Part 3: Connect to the RPG

In your RPG, a goblin's attack damage is 1d6+2. A dragon's breath is 6d8. A critical hit doubles the dice. A stat roll is 4d6-drop-lowest.

For each one: What's the range? What's the average? Write the formula you'd use in Java. (The 4d6-drop-lowest is tricky — you'll need to write it, not just think it.)

Tinker: Loot Table

Design a loot drop system with weighted randomness:

  • Roll a d100 (1–100)
  • 1–50: "Common: Iron Sword"
  • 51–80: "Uncommon: Steel Shield"
  • 81–95: "Rare: Flaming Axe"
  • 96–100: "Legendary: Dragon Slayer"

Run it 20 times. Does the distribution match your design?

Checkpoint — before moving on, you must be able to:

  • Write the random formula from scratch, correctly, every time
  • Predict what ANY casting/parentheses combination will output
  • Design a weighted random system using if-else ranges
  • Explain why (int) Math.random() * 6 always returns 0 — to a classmate, in plain English
