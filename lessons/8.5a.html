8.5a — Pixel Arrays: Images Are Just 2D Arrays

Season 2: beyond the exam. This topic is no longer tested (the 2025 CED removed inheritance from the exam). We build it after May 12 because it makes the RPG engine dramatically better, and because you are ready for it. Pure craft, zero test anxiety.
Discovery Lab ~20 min

A grayscale image is a 2D array where each cell is a brightness value from 0 (black) to 255 (white). Color images are three 2D arrays stacked — one each for red, green, and blue. Every Instagram filter you've ever used is just a 2D array algorithm.

Part 1: Build a Pixel Image

Create a 2D int array representing a 10×10 image. Fill it with a pattern you design:

int[][] image = new int[10][10];

// Draw a diagonal line (top-left to bottom-right)
for (int i = 0; i < image.length; i++) {
    image[i][i] = 255;
}

// Print it as ASCII art
for (int row = 0; row < image.length; row++) {
    for (int col = 0; col < image[row].length; col++) {
        if (image[row][col] > 200) System.out.print("██");
        else if (image[row][col] > 100) System.out.print("▒▒");
        else if (image[row][col] > 0) System.out.print("░░");
        else System.out.print("  ");
    }
    System.out.println();
}

Run it. What shape do you see? Now modify the loop to draw an X, a cross, and a hollow square. Each shape is just a different condition.

Socratic Checkpoint

  1. The code writes to image[i][i]. What's image[i][col] for all other columns? What value does Java put there?
  2. How would you write to image[row][9-row] to draw the other diagonal? Try it. What shape do both diagonals together make?

Part 2: Brighten and Darken

Write two methods that modify every pixel:

  • brighten(int[][] img, int amount) — add amount to every pixel
  • darken(int[][] img, int amount) — subtract amount from every pixel

Bug Hunt: Clamping

Brighten a pixel at 250 by +20. If you don't clamp, what happens? Does your value wrap to something tiny? Does Java let you go past 255? Test it with System.out.println(255 + 20). Then fix it: after every operation, values must stay in [0, 255].

Part 3: Invert and Threshold

  • invert(int[][] img) — replace every pixel with (255 - pixel)
  • threshold(int[][] img, int cutoff) — pixels above cutoff become 255, below become 0. This transforms a grayscale image into pure black and white.

Tinker: Gradient Generator

Fill a 50×50 image with a smooth gradient. Top row = 0, bottom row = 255, and every row in between gets a linearly interpolated value. Print the center row — it should be exactly 127. Now brighten the whole image by 50 and check: is it still a smooth gradient? Where did it clip?

Checkpoint — before moving on, you must be able to:

  • Treat a 2D int array as a grayscale image
  • Apply brighten, darken, invert, and threshold operations
  • Clamp pixel values to [0, 255] to prevent overflow
  • Explain why images are the perfect application for 2D arrays
