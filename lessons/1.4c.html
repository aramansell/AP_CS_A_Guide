1.4c — Slot Machine: Payouts & Polish

Expand Application ~20 min

Your slot machine works, but it's basic. A real slot machine has different payout tiers, a running balance, and feels like a game — not a math problem. Time to expand it.

Requirement 1: Payout Tiers

Right now you have a binary "JACKPOT or nothing" system. Add these tiers:

  • Three match: JACKPOT — multiply bet by 10
  • Two match: Small win — multiply bet by 2
  • No match: Lose the bet

Bug Hunt: The Pairing Problem

Here's a naive approach to checking for two-of-a-kind:

if (reel1 == reel2 || reel1 == reel3 || reel2 == reel3)

Run your slot machine with this check. Then run it again. And again. When three reels match, what happens? Does the program print BOTH "Small win!" AND "JACKPOT!"? What logic do you need to add to fix this?

Requirement 2: Running Balance

Track a balance that persists between spins:

  • Start with 100 coins
  • The player bets 10 coins per spin
  • After each spin, show: bet, win/loss amount, new balance
  • Game ends when balance reaches 0 — print a summary

Socratic Checkpoint

  1. You need the balance to survive across spins. Where in the program do you declare it? Why can't you put it inside the spin logic?
  2. Your payout tiers check three reels for equality. How many if statements did you write? Could you reduce them using a different approach?
  3. What happens when you bet 10 but your balance is 5? Should your program let that happen? How would you prevent it?

Requirement 3: Polish the Output

Make it look like a real game:

═══════════════════════════
  SLOT MACHINE
  Balance: 85 coins
═══════════════════════════
  [ Cherry | Lemon | Cherry ]
  Two of a kind! You win 20 coins!
  New balance: 105 coins
═══════════════════════════

Tinker: Push It Further (pick one)

  • Add a "double or nothing" option after a win — flip a coin (50% chance), double your winnings or lose it all
  • Track total spins, total wins, and net profit. Print final stats when the player busts.
  • Add a "Lucky 7" special payout: if any reel shows 7, return half the bet regardless of matching

Checkpoint — before moving on, you must be able to:

  • Implement multi-tier conditional logic (three match / two match / none)
  • Track state that changes across multiple operations (running balance)
  • Prevent overlapping conditionals (three-of-a-kind also triggers two-of-a-kind check)
  • Format output into clean, readable game displays
